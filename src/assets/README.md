# TrueTrack identity

The mark combines two readable T forms, a mouse-inspired contour and a motion arrow. The wordmark is rendered as live Segoe UI Bold text in the Windows application for readability. The mark is embedded in the executable and supplied as a Windows ICO with 16, 24, 32, 48, 64, 128 and 256 pixel sizes.

Design direction: technical sports identity for FPS players, mint #6DDAB6 against charcoal #13181B. Taste-skill settings applied to the identity: design variance 7, motion 1 (static mark), visual density 2. Website layout rules are not applied to the native calibration interface.

Generated with the built-in image generation tool. Final generation prompt:

> Art-direct a sharper final TrueTrack identity from previous reference, using restrained high-end technical sports design principles: one strong silhouette, consistent geometry, purposeful negative space, excellent readability, no decoration. Retain the mouse-inspired rounded rear contour, the dynamic up-right motion arrow and two unmistakable separate uppercase T letters with a subtly angular pistol-grip-like silhouette. Make the two T top bars horizontal and clean; give each its own full stem and ample negative space. Integrate the arrow with the outer mouse contour so the whole symbol feels one coherent idea, not three cliparts. Mint green solid flat fill #6DDAB6. Transparent background. Square centered app icon with 15% clear margins. No wordmark (typeset separately), no slogan, no gradients, bevels, shadows, texture, swoosh clutter, or hairline detail. Output one finished symbol only.

`truetrack.png` is the generated source. `truetrack.ico` is a format conversion for Windows, preserving transparency. The app keeps internal VectorFit names and measurement paths for compatibility.
