# TrueTrack identity

The original TrueTrack mark combines an angular double-T silhouette with a motion arrow. The wordmark is rendered as live Segoe UI Bold text in the application for readability. The mint mark has a transparent background and is embedded as a PNG and a Windows icon at 16, 24, 32, 48, 64, 128 and 256 pixels.

Generated with the built-in image generation tool using this prompt:

> Use case: logo-brand. Create a single finished app symbol for TrueTrack, a mouse movement calibration and aim practice Windows app. No text. A distinctive clean geometric mint-green continuous motion arc converging into a precise angular arrow, subtle double-T negative space, legible at 32 pixels. Flat solid shapes, no gradients or shadows, no crosshair, no gaming mascot. Centered square composition with modest padding. Palette mint #6DDAB6 on transparent background. Professional restrained identity matching a charcoal desktop UI. One symbol only, no mockups or variants.

The ICO is a format conversion of the generated PNG. Internal VectorFit names and measurement paths remain for compatibility.
